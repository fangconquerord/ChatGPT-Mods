# ChatGPT-Mods

**Браузерное расширение, которое добавляет в интерфейс ChatGPT то, чего там не хватает.**

Сплит-экран · Локальное улучшение промтов · Сохранение временных чатов · Показ прикреплённых файлов

---

## Возможности

### ✨ Локальный Prompt Compiler

Кнопка с карандашом рядом с полем ввода анализирует запрос полностью локально: определяет одно из 39 намерений, сохраняет код, команды, пути, числа и ограничения, строит несколько вариантов и автоматически выбирает лучший. Используются только детерминированные правила и эвристики — без нейросетей, API, моделей и передачи текста из браузера.

Простые или уже хорошо сформулированные запросы не раздуваются. Если критических данных не хватает, компилятор добавляет только необходимые уточнения. Повторное улучшение идемпотентно.

### ↔️ Сплит-экран
Два чата рядом на одном экране с перетаскиваемым разделителем. Удобно для сравнения ответов или параллельной работы в двух контекстах.

### 🗂️ Папки, цвета и иконки чатов
Локальная организация истории в боковой панели: создавайте сворачиваемые папки, назначайте чатам цвет и одну из расширенной коллекции иконок. Обычные кнопки закрепления и меню ChatGPT остаются нативными; закреплённые чаты не переносятся в пользовательские папки. Если чат удалён или перемещён в стандартный проект, его локальное оформление удаляется.

### 💾 Сохранение временного чата
Кнопка **«Сохранить»** в шапке временного чата. Собирает историю диалога и переносит её в новый обычный чат — так разговор не потеряется.

> Это перенос контекста через структурированный промпт, а не серверная конвертация чата.

### 📎 Список прикреплённых файлов
Компактный индикатор с тултипом, если к сообщению прикреплено несколько файлов.

## Установка

> Расширение устанавливается вручную как unpacked extension (Chrome / Chromium).

```bash
git clone https://github.com/medvedeff-true/ChatGPT-Mods.git
```

1. Откройте `chrome://extensions`
2. Включите **Режим разработчика**
3. Нажмите **Загрузить распакованное расширение**
4. Выберите папку репозитория
5. Откройте `https://chatgpt.com/`

## Структура

```
ChatGPT-Mods/
├── manifest.json
├── content-chat-organizer.js # Локальные папки, цвета и иконки чатов
├── content-split-view.js   # Сплит-экран
├── content-temp-chat.js    # Сохранение временного чата
├── content-message-meta.js # Время и список файлов
├── content-prompt-enhancer.js # Кнопка и интеграция с composer
├── prompt-compiler/       # Локальный алгоритмический движок и JSON-правила
├── tests/                 # Unit, integration и golden-тесты
├── benchmarks/            # Проверка производительности
└── icons/
```

## Приватность

Расширение работает полностью локально:
- не обращается к сторонним API
- не собирает аналитику
- не отправляет данные куда-либо

Разрешение `storage` используется только для временной передачи данных между вкладками при сохранении временного чата.

Подробная архитектура и команды разработки описаны в [документации Prompt Compiler](prompt-compiler/README.md).
